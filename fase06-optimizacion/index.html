Explicación Profesional de la Consola (F12)

Las Herramientas de Desarrollador del navegador son indispensables para auditar código en vivo, depurar errores y verificar la conectividad de red.

1. Pestaña Elements (DOM)

Permite inspeccionar la estructura HTML en vivo y auditar selectores CSS, validando cómo actúan los estilos sobre los contenedores.

2. Pestaña Console (Depuración)

Muestra registros del sistema mediante console.log(), errores de ejecución o trazas de objetos en formato de tabla con console.table().

3. Pestaña Network (Red y APIs)

Audita peticiones HTTP asíncronas. Vital para comprobar estados 200 OK y examinar la estructura JSON devuelta por servicios externos.
